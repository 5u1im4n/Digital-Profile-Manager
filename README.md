# 📁 Digital Profile Manager

مشروع ويب متكامل لإدارة الملفات الشخصية الرقمية. تم تصميم المشروع للأغراض التعليمية لفهم تقنيات تطوير الويب وتنظيم البيانات.

## ✨ المميزات الرئيسية

### ✅ إدارة الملفات الشخصية
- إنشاء وعرض وتعديل وحذف الملفات الشخصية
- نظام بحث متقدم مع ترتيب حسب درجة المطابقة
- عرض بعدة أنماط (شبكة، قائمة)

### 🔒 نظام تقييم المخاطر
- تقييم تلقائي لمستوى الخطورة لكل ملف
- توزيع الملفات حسب مستوى الخطورة (منخفض، متوسط، مرتفع)

### 📊 لوحة تحكم وإحصائيات
- إحصائيات حية عن عدد الملفات وتوزيعها
- رسوم بيانية لتوزيع البلدان ومستويات الخطورة

### 🧠 تحليل ذكي بالذكاء الاصطناعي
- تحليل اكتمال البيانات لكل ملف
- تنبؤ بالقيم الناقصة بناءً على الأنماط
- توصيات ذكية لتحسين الملفات
- اكتشاف الشذوذ والقيم غير المعتادة

### 📤 نظام تقارير متكامل
- تصدير البيانات بصيغ متعددة (CSV, JSON, HTML, Text)
- تقارير HTML جاهزة للطباعة
- نسخ احتياطي كامل للبيانات

## 🛠️ التقنيات المستخدمة

- **HTML5** - هيكل الصفحات
- **CSS3** - الأنماط والتصميم (Grid, Flexbox, Custom Properties)
- **JavaScript ES6+** - المنطق والتفاعل (Classes, Modules, LocalStorage)
- **Font Awesome** - الأيقونات
- **Google Fonts** - خطوط عربية (Cairo)
- **LocalStorage** - تخزين البيانات محلياً
