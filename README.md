# 📁 Digital Profile Manager

**مشروع ويب تعليمي لإدارة الملفات الشخصية الرقمية**، يهدف إلى فهم تقنيات تطوير الويب وتنظيم البيانات بطريقة عملية.

## 🔗 الموقع التجريبي
[DPIM على Netlify](https://dpim.netlify.app/)

## ✨ المميزات الرئيسية

### ✅ إدارة الملفات الشخصية
- إنشاء، عرض، تعديل، وحذف الملفات.
- بحث متقدم وترتيب حسب درجة المطابقة.
- عرض متعدد الأنماط: شبكة أو قائمة.

### 🔒 تقييم المخاطر
- تصنيف الملفات حسب مستوى الخطورة: منخفض، متوسط، مرتفع.
- تحديث تلقائي للإحصائيات حسب مستوى الخطر.

### 📊 لوحة تحكم وإحصائيات وتحليل ذكي
- إحصائيات حية حول عدد الملفات وتوزيعها.
- رسوم بيانية لتوزيع البلدان ومستويات الخطورة.
- تحليل اكتمال البيانات لكل ملف.
- تنبؤ بالقيم الناقصة وتقديم توصيات ذكية.
- اكتشاف القيم الشاذة وغير المعتادة.

### 📤 تقارير ونسخ احتياطي
- تصدير البيانات بصيغ: CSV, JSON, HTML, Text.
- نسخ احتياطي كامل للملفات.
- تقارير HTML جاهزة للطباعة.

## 🛠️ التقنيات المستخدمة
- **HTML5** – هيكل الصفحات.  
- **CSS3** – تصميم متجاوب (Grid, Flexbox, Custom Properties).  
- **JavaScript ES6+** – المنطق والتفاعل (Classes, Modules, LocalStorage).  
- **Font Awesome** – الأيقونات.  
- **Google Fonts (Cairo)** – خطوط عربية.  
- **LocalStorage** – تخزين البيانات محليًا.

## 🚀 تشغيل المشروع محليًا
1. انسخ ملفات المشروع إلى مجلد على جهازك.  
2. افتح `index.html` في أي متصفح حديث.  
3. استخدم الواجهة لإضافة وعرض الملفات مباشرة.
